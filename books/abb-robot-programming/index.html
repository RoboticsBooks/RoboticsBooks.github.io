ABB Robot Programming: RAPID methods that work in production

By Guillaume Olivier. Available in paperback and Kindle.

Learn the RAPID programming methods used in real industrial projects. Every example is built with RobotStudio and the virtual FlexPendant, from your first routine to a complete production program with missions, PLC handshakes and World Zones.

What you will be able to do

  • Use RobotStudio and the virtual FlexPendant to write your first RAPID programs
  • Use program data, procedures and functions for clean, reusable code
  • Define tooldata, work objects and payloads correctly
  • Program relative motion and use frames to keep programs flexible
  • Protect your cell with World Zones and an automatic return to home
  • Handle I/O signals and design clean handshakes with the PLC
  • Structure a real main program with missions, as used on production lines

Who this book is for

Robot technicians, automation engineers, integrators and students, whether you are new to robotics, coming from another robot brand, or already programming ABB robots.

Why this book is different

Written by an automation engineer with years of field experience in industrial robot cells. No theory for its own sake: only methods proven during commissioning, and complete examples you can reproduce in RobotStudio.
