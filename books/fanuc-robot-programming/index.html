FANUC Robot Programming: field-tested TP methods, built in Roboguide

By Guillaume Olivier. Available in paperback and Kindle.

Write FANUC robot programs that run reliably on the shop floor. Every example is built and tested in Roboguide, so you can follow along on your PC without a real robot, from an empty workcell to a complete production-ready program.

What you will be able to do

  • Build a complete robot cell in Roboguide and write your first TP programs
  • Use registers, position registers and frames instead of hard-coded points
  • Define tools and payloads correctly and choose between joint and linear motion
  • Handle I/O and design clean handshakes with the PLC
  • Structure a real main program with missions, as used on production lines
  • Add Space Check, reference positions and automatic return to home
  • Run Background Logic tasks and manage messages and alarms

Who this book is for

Robot technicians, automation engineers, integrators and students who know the basics of a teach pendant and want to write cleaner, more robust FANUC programs.

Why this book is different

Written by an automation engineer with years of field experience in industrial robot cells. No theory for its own sake: only methods proven during commissioning, and complete examples you can reproduce in Roboguide.
