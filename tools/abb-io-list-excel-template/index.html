ABB robot I/O list Excel template

List your signals and generate the EIO.cfg declarations in one click.

Creating an Excel file to list inputs and outputs is a mandatory step in every robot project. This template lets you fill in digital and group inputs/outputs, then a macro generates the signal declarations ready to paste into EIO.cfg.

Download the Excel template (.xlsm)

Macro-enabled workbook. Tested with RobotWare 6.15.03. Excel will ask you to enable macros.
