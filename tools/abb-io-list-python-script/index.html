ABB I/O list from a robot backup (Python)

Python scripts that convert EIO.cfg to an Excel I/O list, and back.

Two Python scripts for ABB robots: one creates an inputs/outputs Excel list from a robot backup, the other does the reverse and generates EIO.cfg signal declarations from the Excel list.

Download the scripts (.zip)

EIO.cfg to Excel

  1. Copy the EIO.cfg file (in the SYSPAR folder of the robot backup) into Convert_EIO_to_IOExcelFile/From.
  2. Run Execute script.bat.
  3. The IO_List.xlsx file in the To folder is filled with all DI, DO, GI and GO signals, sorted by device and address. A CSV copy is created too.

Excel to EIO.cfg

  1. Fill in IO_List.xlsx in Convert_IOExcelFile_To_EIO/From.
  2. Run Execute script.bat.
  3. Paste the signals from To/EIO.cfg into your configuration and load it with RobotStudio.

Requirements

Tested with RobotWare 6.15.03 and Python 3.10. Install Python 3, then the openpyxl package:

python -m pip install openpyxl

I/O declarations differ slightly in RobotWare 5.x; the scripts can be adapted. Prefer Excel without Python? Use the ABB I/O list Excel template.
