FANUC I/O list from a connected robot (Python)

Python script that reads a real or Roboguide robot and fills an Excel I/O list.

This Python script creates an inputs/outputs Excel list from a connected FANUC robot, real or virtual in Roboguide. It reads the robot's I/O status page over the network, so there is nothing to export by hand.

Download the script (.zip)

How it works

  1. Run the script with Execute script.bat.
  2. Keep the default IP address 127.0.0.1 for a Roboguide robot, or enter the real robot's IP address.
  3. The IO_List.xlsx file in the To folder is filled with all signals: DI, DO, GI, GO, UI, UO, RI and RO.

Requirements

Tested with controller software V9.40 and Python 3.10. Install Python 3 (available from the Microsoft Store), then open a command prompt and install the packages:

python -m pip install requests beautifulsoup4 openpyxl

Do not delete IO_List.xlsx from the To folder: the script writes into it.
