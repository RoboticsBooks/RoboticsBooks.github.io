Notepad++ syntax highlighting for RAPID, TP and VAL3

User-defined language files for ABB RAPID, FANUC TP and Stäubli VAL3.

These user-defined language files add syntax highlighting to Notepad++ for robot program files, which makes backups much easier to read.

Downloads

  • ABB RAPID (.mod, .sys)
  • FANUC TP (.ls)
  • Stäubli VAL3

How to install

  1. Open Notepad++ and go to Language › User Defined Language › Define your language.
  2. Click Import and select the downloaded .xml file.
  3. Restart Notepad++. Files with the matching extension open with highlighting.
